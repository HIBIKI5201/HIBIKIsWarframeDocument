## 詳細

### あらすじ

Stalker は Jade の息子に Sirius か Orion と名付ける。永続主義により、選ばれなかった方の息子が存在する破滅した未来の時間軸が生まれる。20 年後の未来から Sirius と Orion の二人が、師である Ryoku と Vena を連れて現在に現れ、それぞれの目的のために Stalker を引き込もうとする。

子である Natah と Erra を救えなかった Hunhow は、息子たちの争いを断ち切るため Stalker に手を貸す。二人は、同じく息子を失った父である Excalibur Umbra を仲間に加える。Stalker は Ryoku と Vena を倒して Sirius と Orion をおびき出し、Void の火花（Void Spark）を手に入れる。Hunhow はそれを使って自らの記憶を無関心（The Indifference）に捧げ、争いを終わらせ、二つの選択肢が共存する空間を作り出す。

### トリビア

- 父親をテーマにした内容で、父の日（2026-06-21）の直前に公開された。
- ロードアウトに関係なく、Umbra は Sunder ヘルメットを着けた初期の姿で登場する。
- Jade Shadows と同じく、隠れんぼの場面のオービターは、隠密の邪魔にならないよう装飾がすべて外されている。
- Ordis の声を Kevin Lim が担当した最初のクエスト。初代の Mike Leatham が引退したため。
- Whispers in the Walls をクリアしていなくても、Protoframe と Murmur が登場する。
- Murmur が Void 系の場所（Void、Deimos、Zariman）以外に現れた初めての例。ただし Void Spark のエネルギーで歪んだステージではある。Höllvania にも The Hex の終盤に現れているが、そこには無関心自身がいた。
- Drifter が Helminth の口に入り込む話が出てくる。これは The Hex で起きる出来事。
