## 詳細

### あらすじ

眠りから目覚めた Sentient Hunhow は、Old War での行いへの復讐を Tenno に誓う。Stalker と手を組んだ彼は、「空の胎（womb in the sky）」を破壊しようとする。それは Tenno の弱点、つまり Lotus が Sentient から守るために Void の中に隠したルアのリザーバーだった。

プレイヤーは、Natah の一件で Lotus の心に入り込んだ Hunhow を探すことになる。思いがけず Alad V の協力を得て、手がかりは Grineer が天王星で掘り出した Sentient の遺物にたどり着く。Lotus は遺物に触れて Hunhow の居場所を探ろうとするが、逆に Hunhow にリザーバーの場所を知られてしまう。Stalker が向かっているため、プレイヤーは先にリザーバーに着こうと後を追う。Stalker を追って Void ゲートをくぐり、Void の中の Orokin の塔に入ると、リザーバーは Void に隠された地球の月にあるとわかる。塔の Void 遮蔽装置を止めると、ルアと呼ばれる月の位置が探知できるようになる。Ordis がプレイヤーを塔から回収してルアに降ろすと、Stalker は Void を崩壊させ始める。ルアが Void の重みで押し潰されるのを防ぐため、プレイヤーはルアを Void の外へ戻す。これでルアは Void に守られなくなり、残された手段はリザーバーを守ることだけになる。

リザーバーの真実は、そこに Tenno の本当の姿、オペレーターが眠っていることだった。オペレーターはリザーバーから Void エネルギーを送って Warframe を遠隔操作していた。これを転移（Transference）という。Stalker はプレイヤーのもとに現れるが、オペレーターを見て殺すのをためらう。プレイヤーは新たに得た力、つまり Void エネルギーを操ってオペレーターの姿で戦う力で、押し寄せる Sentient の戦闘機を退ける。

オービターで、プレイヤーはオペレーターを新しい転移の器、船の奥にあるソマティックリンクに入れなければならない。Stalker との最後の戦いに勝利した後、プレイヤーは初めて Lotus と直接対面する。Lotus が意識のないオペレーターをソマティックリンクに運ぶと、プレイヤーは Tenno だった頃の記憶を一部取り戻し、Orokin の時代（Old War）に属していた 5 つの偉大な流派の一つを思い出す。

> 「これが本当のあなた。Tenno。人間を超えた存在……けれどかつては、どこにでもいる子どもだった」（Lotus）

### トリビア

- Update 14.0 以降、Ordis が時々「夢を分かつな」と口にしており、これが最初の伏線だった。クエストの公開後、この台詞は言わなくなった。Natah でも Lotus が「Tenno を二番目の夢の中に隠した」と語っている。
- WARFRAME で最初のシネマティッククエスト。
- Lotus との会話での返答は、その後に出る流派選択画面の並び順に使われ、最もふさわしい流派が一番左に来る（例:「勉強していたのを覚えている」「私たちは知識を求めた」を選ぶと Naramon が一番左）。どれを選ぶかは自由。
- 二番目の夢の要素は、それ以前のロアにも出ていた。
  - 輸送船 Zariman とその子どもたちの話は、Ember Prime の Codex で初めて触れられ、Rhino Prime の Codex にも出てくる。
  - クエスト中に声が聞こえる Orokin の男 Ballas は、Orokin の執政官会議の一員である Executor Ballas で、Crewman の Synthesis で初めて名前が出ていた。
- Keith Power によると、このクエスト専用の曲の一つでは Jen McMillan が聖歌隊の声を担当している。
