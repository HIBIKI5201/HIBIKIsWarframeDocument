## ストーリー考察の主張

出典は略称で書く。**台本**＝新たな大戦までのストーリー解説 台本、**二夢**・**内紛**・**Harrow**・**犠牲**＝コラボ配信台本集の各回、**X**＝ツイート。

「自説」と書いたものは、本人が自分の説だと明言しているもの。それ以外も、あらすじの説明ではなく本人の解釈・推測にあたる部分だけを拾っている。

### Void・転移

- **転移は睡眠と夢を経由して意識を共有する仕組み**。転移中に脳波（デルタ波）が増えていたのはそのため。Lotus のヘルメットが見せる情景や各クエストの導入ムービーも、転移で見せられている可能性がある（犠牲）
- **転移波通信説**: テンノの通信は転移エネルギーを使っている。転移妨害波が出ると通信も切れること、通信にしては位置や状況を把握しすぎていることが根拠（Harrow、内紛）
- **転移されている側は目の色が変わる**: Erra プロローグで Lotus に操られたオペレーターの目、Rell の影の赤い目、秘匿通信中の Ballas のオレンジの目から（Harrow、犠牲）
- **Void は精神が存在する 4 次元世界**。Ballas の言う「二重性」を心身二元論と解釈し、そこから導いた（犠牲）
- **Void 能力の本質は「可能性の世界の上書き」**。Void は現実にならなかった可能性の世界（Harrow）
- ルアの周りに円形の空間ができていることから、Void は 3 次元の存在を保存するための仮の空間だと推測（二夢）
- ソマティックファイバーの白い管は、Void に生える白い植物（ルナピッチャー、転移装置の背後の植物）と関係があるかもしれない（二夢）
- **Void・Kuva・テクノサイトウイルスはつながっている**。Kuva は模倣者（壁の中の者）の血液とされ、これを摂取したオロキン人は模倣者の思考パターンに擬似的に感染して残虐になる。Warframe 化で狂気に陥るのもテクノサイトウイルスの性質で、これも Void と関係が深い（内紛）
- Ballas の研究室の管を流れる青い液体と、Rell の寺院の感染体の赤い光は、同じ Kuva 由来の現象かもしれない。ただし証拠が少ないと本人が注記（犠牲）

### Sentient

- **Sentient は一族で一つの生物**。Hunhow が脳、Natah が眼、Praghasa が口、Erra が神経にあたる（二夢）
- Sentient は機械生命体だが、生物の細胞構造を分析した結果「最も効率的な形」として生物的な肉体を選んだのかもしれない。そのせいでテクノサイトウイルスが弱点になった（二夢）
- **Sentient のエネルギーは「反 Void 物質」でできている説**。Void 粒子と対消滅するから Void に弱いが、肉体そのものは耐えられるのでアンプやアルケインは動く。本人も「突拍子のない説」と注記（犠牲）
- Hunhow は実はリザーバーの場所を知らず、知っているふりをして Lotus に自分の破片を触らせた（二夢）
- Hunhow の「最後の時にキミは Sentient に接近し全ての文明社会を消し去った」は、Lotus 個人ではなく「The Lotus 部隊」全体の話。Natah は洗脳の上から Sentient に一時的に命令され、The Seven 抹殺とオロキン崩壊が起きたが、Margulis の移植でテンノに愛着を持っていたため、テンノだけは殺せなかった（二夢）
- ミミックは各地に擬態して諜報を続けていた。Natah がミミック隊を指揮し、Natah を連れ出した Ballas が間接的にミミックを操っていた可能性（犠牲）
- 登場していないが、Eidolon のような別の「王」がいる可能性（二夢）

### Lotus・Natah・Margulis

- **Lotus は善意で協力していたのではない**。スパイとしてテンノが唯一信頼する Margulis の姿を真似て潜入したところをオロキンに捕まり、ヘルメットで Margulis の思考を植え付けられた傀儡（二夢）。台本では、Natah を迎え入れて Lotus に仕立てたのは Ballas だとしている（台本）
- **ヘルメットの中に Margulis の完全なコピーの意思がある可能性**。接続装置のエラーコードの最後に「おやすみ、可愛い天使」と書き足されていたことから。管を外されてもヘルメット自身が考え続けられる（犠牲）
- Lotus はソマティックファイバーで転移装置とつながっていて、Natah の「Void の眼」を通してオペレーターに両女王や Stalker と Hunhow の密会を見せていた（内紛）
- リザーバーは Margulis が作り、処刑後に Lotus が引き継いだ（内紛）。二夢では「Warframe が本格導入されてから設置された」とも書いていて、記述が揺れている
- **Margulis はテンノから漂流期の記憶を消した**。大人への異常な敵意を抑えるためだが、同時に Void 能力の感覚も忘れさせた。リザーバーに入らなかった Rell だけは覚えている。テンノにとってこれは誠実な対処ではなかった（内紛）

### テンノ・Zariman

- **Zariman は何度も出現と消失を繰り返している**。Margulis が Zariman で長く過ごしたことや、The New War のトレーラーで外が現実の宇宙に見えることから（二夢）
- 遭難していた期間は現実の時間で数年（二夢）
- 5 つのフォーカスは、DAX から武術を学んだテンノが流派として立ち上げたもの。Zariman にフォーカスの絵が飾られているので、当時はまだ Zariman から転移していた（二夢）
- 「Tenno」の名前は Zariman Ten Zero の 10 と 0 から（台本）
- **テンノが成長しない理由の候補**: リザーバーに冷凍睡眠機能がある、Void 能力が時間をずらして老化を遅らせる、オロキンの長寿技術。Rell が不老ではなかったので、Void 能力だけでは説明できない（Harrow）
- テンノの反乱の理由は、オロキンの圧政から人々を解放するためという説が主流（台本。一般的な説の紹介）

### Warframe・Umbra

- **自説: Warframe の素体の意識は消えておらず、眠っているだけ**。薬品で感覚を遮断されているにすぎない。Excalibur の剣術パッシブのような能力は素体由来で、これが出るのは素体の意志がオペレーターに流れ込んでいる証拠（二夢）
- **自説: 二番目の夢で Stalker が手を離した後も Warframe が動いたのは、War を胸に刺された刺激で素体の意識が一時的に目覚めたから**。有名な「オペレーター→Stalker→Hunhow→War 経由で転移がつながった説」は、Stalker が手を離した後も動いた点が不自然（二夢）
- **Umbra 型の仕組み**: Ballas は素体自身に転移ボルトを付け、発狂する前に素体の精神を隔離して自分の体に転移させた。これでテンノのいらない Warframe ができた。精神の分離には Kuva を使い、Cephalon の作り方に近いかもしれない（犠牲）
- Umbra への転移で流れが逆向きになるのは、素体が Umbra に転移しているので、オペレーターが Umbra に入ると結果的に素体がオペレーターに転移するから（犠牲）
- **Umbra 型を作った本当の目的**: 表向きはテンノのいらない Warframe だが、Ballas の本心は、オロキンに逆らえない DAX の制約を利用して、いざという時に Warframe を一斉に無力化すること。Umbra 型が普及していれば Sentient が勝っていたかもしれない（犠牲）
- Warframe の反乱は DAX の制約すら無視しているので、Void による狂気化に近い（犠牲）
- Umbra の記憶の中の「黄金の世界」は素体の思考パターンの記録で、素体の Cephalon を収めた Vitruvian を Umbra の体に内蔵しているような状態（犠牲）
- Stalker とアコライトも Umbra 型の可能性が高い（二夢、犠牲）
- **Protoframe は Warframe より後にできた**。古代大戦で Warframe が活躍していた時期に、Albrecht が Warframe の Helminth 株を使って作ったのが Protoframe（X、[2024-07-31](https://x.com/HIBIKI_5201/status/1818569380382511558)）

### Ballas

- Ballas が Hunhow にリザーバーの位置を流したことで、Erra プロローグのルア攻防戦が起きた（犠牲）
- サクリファイスでグールが襲ってきたのは、Ballas がグールに仕込みをしていたから（犠牲）
- Ballas がオロキンへの忠誠を失ったきっかけは Margulis の処刑（台本）

### オロキン・Kuva・Grineer・DAX

- **Yuvan 劇場の「登り切った者はオロキン人になれる」という噂は嘘**。実際は、優秀な人間の体を新しいオロキン人の器にするための話だった。手順は、Kuva に精神を封じて肉体に注入し、元の精神を絶望で壊して乗っ取る（内紛）
- Teshin のリレーの部屋が雪山なのは、Yuvan 劇場を覚えておくため（内紛）
- **両女王はオロキン出身でも Grineer 出身でもない、人間から生まれた双子**。Kuria の伝承から。Grineer の反乱に加わって祭り上げられ、反乱期にオロキン施設から Kuva を奪い、Grineer の体に精神を移し替えた。「創造主」を名乗るのは Kuva を持っているから（内紛）
- Entrati 一家に悪意がないのは、Deimos が Void に遭難して模倣者と関わったからか、Albrecht が Kuva の狂気を解毒する方法（レクイエム文字）を作ったから（内紛）
- オロキン人は全員がオロキンの母星出身ではなく、功績で昇格した者もいる。Entrati 家もそうではないか（二夢）
- Ordis（Ordan Karris）にとってルアは墓標のような場所（二夢）
- **The New War 後の Ordis の体は Entrati 家が作った**。Vitruvian に設計図があり、Otak を Loid に移植した前例がある（内紛、犠牲）
- **DAX の階級は鎧の色で決まり、ヘルメットは役職で決まる**。金＞銀＞茶＞薄橙。Varzia や Bishamo のヘルメットは指揮官か Railjack の乗員（海軍）かもしれない。Umbra の素体は将軍・元帥級（犠牲）
- スペクター粒子は Void 由来の技術で、模倣者が人の名前や行動を真似るのに近い（内紛）
- Lotus 組織にはリザーバーの防衛隊がいたので、太陽系の各地にテンノ勢力の前線基地がある可能性（内紛）

### Rell・壁の中の者

- **壁の中の者がテンノに Void 能力を与えた張本人**（Harrow）
- Rell は 500 年以上も壁の中の者を封じてきた。Palladino の祖母の代から巫女がいることと、人の寿命を 200 歳ほどと見積もったことから（Harrow）
- Red Veil の信者が狂ったのは、Rell を通して壁の中の者が転移エネルギーで感情や記憶を送り込んだから。Zariman の大人の狂気化や、天使の声による狂気化も同じ原理かもしれない（Harrow）
- Rell が Red Veil に預けられたのは、Margulis が嫌ったからではなく、転移装置を扱えなかったから（Harrow）
- Palladino が Lotus の正体を知っていたのは、Red Veil 側に Warframe の技術者がいたからかもしれない。Rell が使っていた Harrow は通常版（テンノ勢力が作り直したもの）なので、両者にはつながりがある（Harrow）
- Rell の封印がテンノに移ってから、Natah は Void の眼で壁の中の者が見えるようになった。つまり壁の中の者は前より自由になった（Harrow）
- Rell の母 Kay の言う「彼女」は Kavat（Harrow）

## 二次創作「栄光なる悪魔」の独自設定

本人の説明では、この小説の目的はストーリー考察で、一部に独自設定と自己解釈を含む。例として「主人公の父親が DAX」「狂気化は模倣者が主犯」を挙げている。

物語で使われている主な設定:

- **主人公**: Hibiki。父は DAX の大隊長 Valia、母は Void 技術者の Archimedean Marsy。伯父は Entrati 家に雇われていた Archimedean
- **Zariman の狂気化は模倣者（壁の中の者）が起こした**。模倣者は Albrecht の「Void の中のドッペルゲンガー」と同じ存在で、人の姿を真似る
- DAX の鎧は Void エネルギーを使っているので、狂気化の進み方が遅い
- 子供たちは模倣者と「契約」して Void の力を得た
- Zariman の子供たちが自分たちで 5 つの流派（Madurai、Unairu、Vazarin、Zenurik、Naramon）を作った
- Margulis を傷つけたのは Madurai の警備班。その後、子供たちと Grineer の間で「Zariman 協定」が結ばれ、補給と引き換えに Void 能力の実験に協力した
- Tau には Sentient 計画が送られ、The Seven は Zariman 計画の失敗を隠したがっていた
- 最初の Warframe（148-H モデル）の素体は、主人公の幼なじみの DAX である Arthur。親友は DAX の将軍 Rex の息子 Issah
- 転移の後遺症で Warframe の素体の意識が操縦者に流れ込む（「残響症」）
- テンノの記憶を消したのは、Margulis の遺言を受けて主人公と Archimedean Silvania が作った精神調整剤
- Es（DAX の諜報課）が Valkyr を操る

## ゲームバランスの主張

ストーリーとは別だが、同じく pixiv にまとめている主張。

- **高難易度の耐久力不足**（[リンク](https://www.pixiv.net/novel/show.php?id=17622708)）: 敵の火力に対して耐久を上げる手段が足りず、無敵化（シールドゲーティングなど）か透明化に頼るしかない。進行度に応じて耐久ボーナスを得られ、自由に割り振れる仕組みを提案
- **照準武器と範囲武器の格差**（[リンク](https://www.pixiv.net/novel/show.php?id=17648874)）: 範囲武器が強すぎて照準武器が使われない。U32 の弾薬変更は方向性として評価しつつ、照準武器側の強化（一時的なオートエイムなど）が必要
- **センチネル救済**（[リンク](https://www.pixiv.net/novel/show.php?id=17676662)）: 他のコンパニオンより耐久が低い。センチネル用の枠を増やし、他のコンパニオンと同時に連れて行けるようにする案
- **Mercy 救済**（[リンク](https://www.pixiv.net/novel/show.php?id=17721530)）: 体力 40% 以下という条件が今の高火力環境では難しく、見返りも少ない。Mercy のたびにバフが溜まるゲージなどを提案
- **初心者向けチュートリアル**（[リンク](https://www.pixiv.net/novel/show.php?id=17745612)）: 全ジャンクションの報酬に Endo を追加、火星のジャンクション課題に Saya's Vigil、低レベル Eximus のオーバーガード削減、二番目の夢で選んだフォーカスにポイント付与、トレードを提示形式にする
- **Nullifier 弱体化**（[リンク](https://www.pixiv.net/novel/show.php?id=17829490)）: アビリティ前提の環境で Nullifier が戦略そのものを壊している。予兆のある設置型フィールドに変える案
- **U32 Veilbreaker の変更**（[リンク](https://www.pixiv.net/novel/show.php?id=18282739)）: 弾薬システムの変更は満点。ただ、照準武器を強化する前に範囲武器を弱体化すると、ブーメラン系近接の一強になる。問題は内容ではなく実装の順番
- **Tier 表は存在する**（X、[2023-04-23](https://x.com/HIBIKI_5201/status/1650069202471092224)）: 「Warframe に Tier 表はない、全部 S ランク」という意見への反論。どのフレームでも攻略できるのは事実だが、それでも Tier 表はあると考えている
- 海外の Warframe 人口の比率についてのツイートもある（[2022-05-29](https://twitter.com/HIBIKI_5201/status/1530763822600187904)）。本文は検索結果に冒頭しか出ず、確認できていない

## 気を付ける点

- 考察のほとんどは 2022〜2023 年（The New War〜Duviri 前後）に書かれている。Whispers in the Walls 以降に明かされた情報（壁の中の者＝Indifference、1999、The Old Peace など）とは突き合わせていない。
- ツイートの日付は、ツイート ID から割り出したもの（UTC）。
